# IBOT Career Ladder — Capability Validation Question Bank

**Purpose:** Evaluate a person's knowledge, reasoning and demonstrated practical abilities against the requirements of their target role.

---

## 1. Questions Based on the 14 Approved Capability Dimensions

| # | Capability Dimension | Assessment Question |
|---|---|---|
| 1 | **Knowledge Depth** | Can you explain one important concept used in your target role, how it works, and when it should or should not be used? |
| 2 | **Practical Execution** | Can you complete a practical task related to your target role and submit the finished work? |
| 3 | **Individual Ownership** | What parts of your submitted work did you personally complete, and which parts involved help from others? |
| 4 | **Problem Solving** | If you encounter an unfamiliar problem in your field, how would you understand it and work toward a solution? |
| 5 | **Decision Making** | If you have two possible approaches to solving a problem, how would you compare them and decide which to use? |
| 6 | **Troubleshooting** | Suppose something you developed or worked on is producing incorrect results. How would you identify and correct the issue? |
| 7 | **Quality Assurance** | How would you verify that your completed work meets the requirements and is free from important errors? |
| 8 | **Independence** | Can you complete the assigned task independently? Record any guidance, tools or assistance you use. |
| 9 | **Communication** | Can you explain your completed work, your decisions and the results to someone who is unfamiliar with the subject? |
| 10 | **Adaptability** | If the requirements of your task change halfway through, how would you adjust your approach and deliver the revised outcome? |
| 11 | **Delivery Reliability** | How would you plan your work to complete a task within an agreed deadline, and how would you communicate any delay? |
| 12 | **Evidence** | What artifacts, outputs or records can you provide to demonstrate that your work meets the assessment requirements? |
| 13 | **AI-Assisted Work** | If you use AI tools to complete a task, how would you verify their outputs and distinguish your contribution from AI-generated work? |
| 14 | **Learning Application** | After learning a new concept or method, can you apply it to a practical problem you haven't solved before? |

## 2. Role-Specific Question Examples

The chatbot modifies the questions according to the user's selected target role.

### Example A — Python Backend Developer

| Assessment Type | Question or Task |
|---|---|
| Knowledge | What happens when a client sends an HTTP request to a backend API? |
| Knowledge | What is the difference between authentication and authorization? |
| Reasoning | You need to store information about customers and their orders. How would you structure the database? |
| Problem Solving | An API becomes slow when many users access it simultaneously. How would you investigate the problem? |
| Decision Making | When would you choose a relational database instead of a document database? |
| Troubleshooting | An API returns HTTP 500 for some requests. What steps would you take to identify the cause? |
| Quality Assurance | How would you test an API before deploying it? |
| Practical Execution | Build a REST API with create, read, update and delete operations using persistent database storage. |
| Adaptability | Modify your API to support an additional validation requirement without breaking existing functionality. |
| Communication | Explain the architecture of your API and demonstrate how it works. |

**Required practical evidence:** Source code, database schema, execution results, test results, assistance declaration and a brief explanation of the implementation.

### Example B — Data Analyst

| Assessment Type | Question or Task |
|---|---|
| Knowledge | What is the difference between correlation and causation? |
| Knowledge | How would you identify missing or inconsistent values in a dataset? |
| Reasoning | Sales have declined over three months. What information would you examine before suggesting possible causes? |
| Problem Solving | Two reports show different revenue totals for the same period. How would you investigate? |
| Decision Making | How would you decide whether to use a line chart, bar chart or table? |
| Troubleshooting | Your calculated results differ from the source data. How would you find the problem? |
| Quality Assurance | How would you verify that your analysis and calculations are accurate? |
| Practical Execution | Analyze a supplied sales dataset, clean the data, calculate key metrics and create a dashboard. |
| Adaptability | Update your analysis when the company changes the reporting requirements. |
| Communication | Present three important insights and explain the evidence supporting them. |

**Required practical evidence:** Dataset transformations, calculation files, dashboard, validation checks, analytical report and presentation.

### Example C — Sales or Business Development Professional

| Assessment Type | Question or Task |
|---|---|
| Knowledge | What stages would you use to organize a B2B sales pipeline? |
| Knowledge | How do you distinguish a potentially interested contact from a qualified sales opportunity? |
| Reasoning | A prospective customer shows interest but has not agreed to a meeting. What would you do next, and why? |
| Problem Solving | Your outreach receives many responses but very few qualified meetings. How would you investigate? |
| Decision Making | You have ten potential customers but limited time. How would you prioritize outreach? |
| Troubleshooting | A sales campaign is underperforming. How would you identify the likely causes? |
| Quality Assurance | How would you check that your customer research and outreach messages are accurate? |
| Practical Execution | Research a fictional target company, identify relevant buyer roles and prepare an outreach and qualification plan. |
| Adaptability | Revise your proposal when the customer's budget or requirements change. |
| Communication | Present your solution in a simulated customer meeting and respond to objections. |

**Required practical evidence:** Customer research document, prospect prioritization, outreach messages, qualification notes, sales plan and recorded simulation evaluation.

## 3. Additional Questions During Practical Assessment

These questions can be asked while evaluating the assigned work.

| Purpose | Question |
|---|---|
| Understand approach | What is your plan for completing this task? |
| Understand decisions | Why did you choose this approach instead of another? |
| Confirm individual contribution | Which parts did you complete yourself? |
| Record assistance | Did you use AI tools, documentation, external resources or assistance from another person? |
| Check quality | How did you test or verify the final output? |
| Handle problems | What was the most difficult problem, and how did you address it? |
| Evaluate adaptability | What would you change if the requirements were different? |
| Capture learning | What did you learn while completing this task? |
| Collect evidence | Can you submit the final deliverables and supporting results? |

These questions provide additional evaluation context. **The answers alone do not demonstrate practical capability.**

---

## 4. Assessment Evaluation Rules

For every role-specific assessment, define:

1. Target role and assessment version.
2. Applicable dimensions from the approved 14.
3. Knowledge questions and expected evaluation criteria.
4. Reasoning scenarios and scoring criteria.
5. Practical tasks and expected deliverables.
6. Mandatory acceptance criteria.
7. Allowed assistance and disclosure requirements.
8. Evaluation results and supporting evidence.
9. Limitations and areas requiring further development.

The evaluation must be based on defined requirements, not the chatbot's general impression of the person.

---

## 5. Three Possible Outcomes

| Outcome | When to assign |
|---|---|
| **Profile Complete** | Sufficient career-profile information has been collected for the current purpose; no verified capability is implied. |
| **Capability Partially Assessed** | Knowledge or reasoning has been evaluated, but sufficient practical performance evidence is unavailable. |
| **Capability Demonstrated** | Relevant practical tasks meet the defined assessment criteria and the evaluation evidence is recorded. |

An incomplete or unsuccessful practical task must not produce a Capability Demonstrated result. Its report should identify the unmet criteria and remaining assessment limitations.

---

## 6. Final Chatbot Instructions

- Keep the original Career Ladder profiling questions unchanged.
- Start Capability Validation only when the person chooses or is appropriately invited to take an assessment.
- Select questions according to the target role and required dimensions.
- Do not ask all 14 questions automatically.
- Assess knowledge and reasoning separately from practical execution.
- Use actual practical tasks, not hypothetical answers, to validate execution.
- Record submitted work, evaluation criteria, results and permitted assistance.
- Generate a report explaining strengths, demonstrated capabilities, limitations and development needs.
- Keep every result specific to the assessed role, assessment scope and version.

**Core principle: Career profiling can be completed through conversation. Capability demonstration requires practical performance meeting defined criteria with recorded evidence.**
